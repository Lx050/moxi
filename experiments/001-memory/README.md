# 001：墨迹记忆

本轮先把即时控制改为显式状态转移：相同输入在不同历史后产生不同响应，随后逐渐收敛。与已有毛笔主页的指针/压力即时映射相比，新增可测的历史依赖，原主页保持原样。

这是为潜空间或世界模型准备的状态接口，不是学习得到的表示，也没有动作条件预测模型。参数是人为设置，工程检查通过仅能证明实现符合该机制，不能证明它有艺术价值或改善控制感。

## 技术路线与已实现内容

气 `qi`、心 `xin`、声 `sheng` 均为 0–1 输入。当前气是手动强度占位，心是手动动作稳定度占位，声是手动声音包络占位。心不是心理测量，气不是实测呼吸。

输入进入 `src/state.mjs`，得到能量、扰动、积墨三个显式状态，再驱动同一绘制轨迹的墨迹粗细、扰动和浓度；对照直接使用当前输入对应的目标状态。三个状态按 0.35、1.2、3 秒时间常数更新，用解析形式避免相同持续输入在不同帧率下产生不同结果。超过 250 毫秒的页面中断会重置并记事件，不伪造连续记录。

1. `npm test` 检查样本率、边界、坏输入、遮挡、平移与本地 OSC 收发。
2. `npm run experiment` 执行协议中的两段 6 秒历史，再给予完全相同的 30 秒探针输入，生成报告与逐帧 JSONL。
3. `npm run serve` 打开浏览器对照原型。按钮注入的是 6 秒模拟历史，非真实采集；下载记录也明确标记为模拟/手动。
4. `npm run osc` 将同一回放的状态发到本机 7400 端口；TouchDesigner 接入见接口说明。当前没有 `.toe` 运行验收。
5. MediaPipe PoseLandmarkerResult 适配器已实现动作稳定度提取及遮挡处理；尚未接入相机。AIGC 只输出固定种子和状态条件包，尚未调用生成模型。

本轮无第三方包、无模型下载、无设备权限和外部模型调用。预计重新运行工程验证不足一分钟；人工浏览器对照约十分钟；后续现场集成另计。

## 最小验证实验

核心假设：安静/活跃两种输入历史结束后，同一探针在 1 秒时仍有可测状态差异，30 秒时收敛。唯一处理变量是历史输入，其余探针、采样率、状态方程、输出轨迹和参数保持一致。即时映射为去除记忆的消融对照。

协议在 `protocol.json` 中预先固定：30 Hz，两段 6 秒历史、30 秒探针，每条件 900 帧，确定性工程回放每条件一次即可复现。用不同采样率、输入极值和坏样本的测试补充，不把重复同一确定性序列当成独立样本。

预设门槛：1 秒欧氏状态差 ≥ 0.1、30 秒差 ≤ 0.001、即时映射历史差 ≤ 1e-12、所有值在 [0,1]。任一不满足则不通过本轮工程检查。记录核心函数耗时 P95，仅作本机性能观察，不替代输入到光子的端到端延迟。

后续真人探索的目标（均未测）：随机呈现 A/B，6 人各做两条件 3 次目标跟踪，记录稳定时间、超调、轨迹误差与 1–7 分控制感；目标端到端 P95 <100ms、状态条件比基线控制感提升 ≥1 分且轨迹误差不增加 >10%。这是探索性设计，不作总体统计结论。本周不自动招募参与者。

## 风险与下一轮

- 滞后可能增强连贯感但削弱控制；支持机制工程假设后，下一轮先实现可重复目标跟踪任务和误差记录，再决定是否保留慢变量。
- 工程差异不足或不收敛：优先查转移实现和尺度，不直接引入大模型掩盖问题。
- 状态差异存在但控制实验不确定：保留参数和结果，做去掉慢变量的消融或重复任务；不宣称提升。
- 姿态遮挡与视角变化会污染代理量；缺失值显式无效，不能以 0 当作真实稳定度。肩宽归一化只消除部分尺度/平移影响。
- AIGC 延迟和输出漂移后续单独验证，当前固定种子条件包不证明图像连续性；低成本降级始终是本地绘制。
- 仓库公开，只保存合成序列与工程结果；任何真人图像/录音留在被忽略的 `private/`，未经明确授权不上传。
